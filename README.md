# Anime Sub ID Search v0.2

Android search engine khusus pencarian anime untuk pengguna Indonesia.

Fitur utama: pencarian metadata anime, poster, filter tipe/status, riwayat pencarian lokal, favorit lokal, dan resolver ke sumber resmi/berlisensi yang relevan untuk Indonesia.

Package: `com.ric.animesubid`
Minimum Android: API 26
